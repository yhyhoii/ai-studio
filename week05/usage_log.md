# Q. .env 파일은 어떤 역할을 하고. gitignore에 env를 기록하는 것은 어떤 의미가 있지?

**AI 답변 요약**
`.env` 파일은 앱 실행에 필요한 **환경 변수(environment variables)** 를 `KEY=value` 형태로 저장하는 설정 파일입니다. 예를 들어 API 키, 데이터베이스 주소처럼 코드에 직접 넣기 곤란한 값들을 보관할 때 씁니다. 앱이 `.env`를 자동으로 읽는 것은 아니며, 보통 `python-dotenv` 같은 라이브러리나 프레임워크 설정을 통해 불러옵니다.

현재 저장소의 `.gitignore`에는 `.env`가 있어, Git이 저장소 안의 `.env` 파일을 추적 대상에서 제외하도록 설정되어 있습니다. 실제 키나 비밀번호가 담긴 파일이 실수로 GitHub 등에 올라가는 일을 막기 위한 것입니다. 프로젝트에는 대신 값의 형식만 안내하는 `.env.example`이 있습니다.

주의할 점은 `.gitignore`가 **이미 Git에 추가된 파일을 자동으로 추적 해제하지는 않는다**는 것입니다. `.env`를 이미 커밋했다면 추적 대상에서 별도로 제거하고, 그 안에 있던 키나 비밀번호도 교체하는 것이 안전합니다.
