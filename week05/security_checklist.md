| 키 관리 | S7 | 키·비밀 값을 print/log/스크린샷으로 전체 출력하지 않았다 | ☑ 예 | 원본의 DB 접속 문자열·요청 헤더 DEBUG 출력 2줄 삭제 |
| AI 사용 | S8 | AI 사용 내역(프롬프트·채택·수정)을 과제 규정에 따라 기록·첨부했다 | ☑ 예 | `usage_log.md` 참고 |
| AI 사용 | S9 | (LLM 기능 포함 시) 사용자 입력 검증과 출력 검증(형식 확인)을 적용했다 | 해당 없음 | 실제 LLM 호출 없음(모의 응답) |
